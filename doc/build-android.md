# Build Android APK

## Prerequisites

- Node.js + npm
- Java (JDK 17+)
- Android SDK (via Flutter/FVM or standalone)
- ADB (for installing to device)
- `ANDROID_HOME` environment variable pointing to the Android SDK

Verify Android toolchain:
```bash
flutter doctor   # if using Flutter SDK
adb version
java -version
```

---

## One-time Setup

Already done in this repo. Listed here for reference:

- `kasir-fe/svelte.config.js` — uses `adapter-static` with `fallback: 'index.html'`
- `kasir-fe/capacitor.config.ts` — appId `com.kasir.pos`, webDir `build`
- `kasir-fe/android/` — Android project (generated by Capacitor)

---

## Configuration

### API URL

Edit `kasir-fe/.env.android` to set the backend domain:

```
VITE_API_BASE_URL=https://kasir-be.kopicode.com/api/v1
```

This file is loaded automatically during `npm run build:android` — no need to touch `.env`.

---

## Build Steps

```bash
cd kasir-fe

# 1. Build frontend with Android API URL
npm run build:android

# 2. Sync web assets into the Android project
npx cap sync android

# 3. Build debug APK
cd android
./gradlew assembleDebug
```

Debug APK output:
```
android/app/build/outputs/apk/debug/app-debug.apk
```

---

## Install to Device

Connect an Android device with USB debugging enabled, then:

```bash
adb install app/build/outputs/apk/debug/app-debug.apk
```

To reinstall (overwrite existing):
```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

---

## Release APK (signed)

```bash
cd android
./gradlew assembleRelease
```

Release builds must be signed before distribution. In Android Studio or via Gradle signing config.

Release APK output:
```
android/app/build/outputs/apk/release/app-release-unsigned.apk
```

---

## CORS

The APK sends `Origin: https://localhost` to the backend.
Ensure `https://localhost` is in `kasir-be/.env`:

```
ALLOWED_ORIGINS=http://kasir.test:5173,http://localhost:5173,https://localhost
```

---

## Known Limitations

- **Bluetooth printing** — Web Bluetooth API is not available in Android WebView. The Bluetooth print button will not appear in the APK.
- **CSS print receipt** — `window.print()` works in the WebView but output quality depends on the Android print service.
